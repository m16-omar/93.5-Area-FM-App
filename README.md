# 93.5 Area FM Flutter App 📻📱

A high-performance mobile application for **93.5 Area FM** ("Voice of the City"), built with Flutter and Dart.

## Features

- 🎙️ **Live Audio Stream**: 24/7 crystal-clear live radio streaming powered by `just_audio`.
- 🎚️ **Stream Quality Selector**: Switch between High Definition (320 kbps), Standard (128 kbps), and Data Saver (64 kbps).
- 🎵 **Persistent Audio Mini-Player**: Sticky player bar visible across all app views with animated soundwave visualizer.
- 📻 **Interactive Radio Deck**: Live presenter details, station statistics, and animated soundwave equalizer.
- 📅 **Program Schedule**: Day-by-day interactive timetable showing show times, presenters, and live badges.
- 🎙️ **Podcasts & On-Demand**: Categorized podcast shows with episode playlists.
- 📰 **Radio News & Blog**: Station announcements, urban news, and article reader.
- 💬 **Studio Connection**: One-tap WhatsApp hotline (`+234 800 935 2732`) and direct phone caller.
- 🌓 **Theme Switcher**: Dark and Light mode themes.

## Getting Started

### Prerequisites

- Flutter SDK (3.38+ / Dart 3.10+)
- Xcode (for iOS build) or Android Studio (for Android build)

### Running Locally

```bash
flutter pub get
flutter run
```

### Running Tests

```bash
flutter test
```
